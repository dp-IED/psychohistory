# Meta (artifacts)

Files here are **session outputs**, not part of the knowledge graph agents traverse for forecasts.

| Path | Contents |
|------|----------|
| `meta/reflections/` | Post-run vault reflections (`_reflection-YYYY-MM-DD*.md`) |
| `forecasts/` (root) | Per-question forecast entries — linked from runs, rarely wikilinked inbound |
| `runs/` | Hermes run notes |
| `simulations/` | One-off simulation outputs |
| `agent-roles/` | Orchestrator roster (read by path, not wikilinks) |

Orphan nodes in Obsidian for these paths are **expected**. Navigate via `_index.md` or file search, not the global graph.
