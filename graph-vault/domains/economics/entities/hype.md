# HYPE (Hyperliquid)

**Type**: Layer-1 blockchain / Decentralized perpetuals exchange native token

## Overview

HYPE is the native token of Hyperliquid, a high-performance Layer-1 blockchain purpose-built for on-chain perpetual futures trading. Hyperliquid differentiates itself through its custom L1 architecture (rather than building on an existing L1 like Ethereum or Solana) that achieves CEX-comparable throughput (~100K+ TPS) and sub-second finality specifically optimized for derivatives trading.

The Hyperliquid ecosystem includes:
- **Hyperliquid L1**: Custom Tendermint-based (Cosmos SDK fork) blockchain optimized for orderbook matching
- **Hyperliquid DEX**: On-chain perpetual futures exchange with spot trading and a capital-efficient cross-margin system
- **HYPE Staking**: Validator-based proof-of-stake securing the network with staking rewards
