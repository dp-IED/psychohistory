# History (out of graph)

The **live vault** is contemporary-only: `timeline/2022+`, `threads/`, `entities/`, `concepts/` used for Polymarket-style forecasting.

Put material here when it is **historical context or retired research**, not an active forecast spine:

| Subfolder | Use for |
|-----------|---------|
| `history/timeline/` | Quarter/annual files before 2022, or deep analog periods (e.g. 1900–1910) |
| `history/threads/` | Long arcs that are analog-only (no contemporary `status: active`) |
| `history/entities/` | Actor stubs for historical figures not named in live markets |
| `history/concepts/` | Pattern notes mined from history but not yet promoted to `concepts/` |
| `history/notes/` | One-off research, cut content from slimmed quarters |

**Rules for agents**

1. Do **not** create new files under `timeline/` or `entities/` for pre-2022-only actors or events — use `history/` instead.
2. Contemporary forecasts may **cite** `history/` in reasoning, but should prefer live `threads/` and `concepts/` first.
3. To **promote** a historical pattern: distill it into `concepts/<slug>.md` with a 2022+ canonical example, or add a subsection on a contemporary thread — do not bulk-import historical entities.
4. Wikilinks from the live graph into `history/` are optional (`[[history/threads/anarchist-wave]]` or plain prose). Do not require reciprocal links from history files into live quarters.
