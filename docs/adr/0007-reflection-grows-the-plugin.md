# Reflection grows the plugin; there is no sidecar vault

After `Y`, Parent grades the claim and the justification, then changes this repository’s plugin so the next due-today is a stronger system: new or rewritten skills, agents, references, scripts/tools, and strategies. Adding files is allowed when the grade earned a new capability. Later reflection culls overlay that failed to transfer.

Durable world knowledge lives in the overlay (usually `references/`), not in `graph-vault/`. Do not restore the old vault corpus. GNN analysis stays parked.

Supersedes the vault-write half of ADR 0004 and the reading of ADR 0002 that treated skill-bloat guardrails as “prefer never add a file.”
