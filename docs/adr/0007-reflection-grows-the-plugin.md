# Reflection grows the plugin; there is no sidecar vault

After **resolution day**, Parent grades the whole claim series, then changes this repository’s plugin so the next predict is a stronger system: new or rewritten skills, agents, references, scripts/tools, and strategies. Adding files is allowed when the grade earned a new capability. Later reflection culls overlay that failed to transfer.

Durable world knowledge lives in the overlay (usually `references/`), not in `graph-vault/`. Do not restore the old vault corpus. Do not restore the France/warehouse GNN tree. A later epoch may add a new simulator (including a GNN) only as overlay `scripts/` / tools when a grade earned that capability.

Supersedes the vault-write half of ADR 0004 and the reading of ADR 0002 that treated skill-bloat guardrails as “prefer never add a file.”
