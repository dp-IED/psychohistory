# Reflection grows the plugin; there is no sidecar vault

After **resolution day**, the reflector grades the whole claim series **and** the overlay system that produced it, then changes this repository’s plugin so the next predict is a stronger system: new or rewritten skills, agents, references, scripts/tools, and strategies. Adding files is allowed when the grade earned a new capability. Later reflection culls overlay that failed to transfer — including scripts and models, not only markdown.

Durable world knowledge lives in the overlay (usually `references/`), not in `graph-vault/`. Do not restore the old vault corpus. Do not restore the France/warehouse GNN tree. When a grade earned it, the reflector authors a **new** simulator or other deterministic tool as overlay `scripts/` / tests (including a GNN). Markdown is not the ceiling (ADR 0019).

Supersedes the vault-write half of ADR 0004 and the reading of ADR 0002 that treated skill-bloat guardrails as “prefer never add a file.”
