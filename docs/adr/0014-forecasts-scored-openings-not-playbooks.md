# Forecasts are scored; openings are not; playbooks are not the product

The long-term use is to help parties such as LFI, DSA, and similar organisations see where a fight can be pushed (Gramsci: long institutional/common-sense fight, and short fight when power is contestable). The system is **multitenant**: not built for one party only. That does not change what the live loop **grades**.

**Scored:** dated **claims** on **problems** (ADR 0009–0010). They live in the repo (`ledger.md`). If a forecast is made in chat, copy an **anonymized** claim into the ledger; the wording the user saw stays in conversation (harness FS only if they ask).

**Allowed, not scored:** **openings** and other one-off analysis. Default: conversation history. Not `ledger.md`.

**Not a product of the grade:** a **playbook** (“do this next”).

Does not add a fourth host job. Does not restore graph-vault.

Glossary: `CONTEXT.md` (**Opening**, **Chat forecast**, **Playbook**, **Tenant**).
