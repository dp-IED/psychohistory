# Forecasting Policy

## Synthesis Heuristics

- **Minimum evidence gate**: Do not converge if `evidence_call_count == 0`. Require at least 1 evidence call for stub_family, 2+ for general/crypto/sports. If the gate cannot be satisfied, emit p=null with reason "insufficient_evidence" rather than falling through to a default.
- **Default probability detection**: Before emitting final_p_yes, compare against known degenerate values [0.5650, 0.5000]. If an exact match is found, the synthesis did not incorporate evidence — abort and re-score.
- **Shrinkage**: Apply shrinkage=0.0384 toward 0.5 when >= 10 resolved episodes exist. Shrinkage pulls extreme forecasts toward 50% to correct overconfidence.
- **Outside-view first**: Always establish a class-level base rate before touching graph-derived numbers. For symmetric/coin-like questions, anchor near 0.5.

## Lessons from Past Runs

### Default-probability degeneration (2026-05-14 backtest)
All 5 worst episodes (Brier 0.3192 each) share an identical signature:
- 0 evidence calls
- 8 retrieved nodes, 3 scoring steps (identical mechanical path)
- `final_p_yes = 0.5650` exactly
- No blind spot checks fired or skipped

This pattern indicates a fallback code path that returns p=0.565 when no evidence is available.

### Latest high-Brier shape (2026-05-15) — general sports / quote events
- Football / sports fixtures: anchor on implied win probability (market or model) as of cutoff, then adjust for injuries, suspensions, rest, home/away.
- Exact wording / "first to say X" during staged events: resolution is lexical and order-sensitive; need phrase base rate, format (who speaks when), and live agenda. Without that, stay near 0.5 and widen uncertainty.
